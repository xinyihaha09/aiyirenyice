# 飞行员“一人一策”数据驱动训练支持系统

完整静态演示项目，包含五大功能交互原型、自然人声风格 AI 女声旁白、原创轻快配乐。

## 模块顺序

知识小管家 → 问答小助手 → 分析小助手 → 报告小顾问 → 数据小参谋。

## 公网演示

[点击访问演示](https://flight-training-one-pilot-20261028.x423830597.chatgpt.site)

## 本地运行

使用任意静态 HTTP 服务器打开根目录 `index.html`。点击播放后启用声音；声音设置可独立开关配乐、旁白和调整音量。

此项目为前端流程演示，数据取自演示录屏中的可见记录；未展示的明细已标注为示意或统计快照。
